# 🎮 Number Guessing Game

A simple C# console-based number guessing game.

## 📌 Description

This is a console application developed using C#. The computer randomly generates a number between 1 and 100, and the player has to guess the number.

After each guess, the program tells the player whether the guess is too high or too low. The program also counts the number of attempts and allows the player to play again.

## 🛠️ Technologies Used

* C#
* .NET
* Visual Studio

## ✨ Features

* Generates a random number between 1 and 100
* Accepts user input
* Provides "Too High" and "Too Low" hints
* Counts the number of guesses
* Allows the player to play multiple times
* Simple console-based interface
